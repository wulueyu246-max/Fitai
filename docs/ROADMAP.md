# 产品路线图

本路线图基于 v1.0 已验证的真实 AI 穿搭链路制定，以下项目均为后续工作，不代表当前已完成。

## Version 1.1：结果质量与留存

- 客户端图片压缩、方向修正和上传质量提示。
- AI Prompt 与 JSON 结果质量评估，提升稳定性与个性化。
- 本地或云端保存 AI 分析历史，支持再次查看与重新生成。

## Version 1.2：衣柜与商品推荐

- 完善我的衣柜与收藏沉淀。
- 将 AI 结果严格关联到可用商品库，避免生成不存在的商品。
- 增加真实联盟商品来源适配层、价格与库存刷新策略。

## Version 1.3：身份与云端同步

- 接入生产级注册、登录、会话恢复与账号注销。
- 云端同步用户画像、收藏、衣柜与分析历史。
- 建立图片私有对象存储、删除机制、数据保留策略与审计日志。

## Version 2.0：试衣与社区

- 接入可替换的真实 AI 虚拟试衣任务服务。
- 建立数字衣橱、搭配保存与跨设备同步。
- 上线审核后的穿搭社区、分享与互动闭环。

## 上线前优先级

1. 生产环境 HTTPS、域名、真实身份系统和密钥托管。
2. 用户照片的私有存储、授权、删除与合规流程。
3. AI 成本、限流、监控、告警与异常重试策略。
