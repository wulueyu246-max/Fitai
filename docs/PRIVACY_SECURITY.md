# Privacy and Security Baseline

FitAI 会处理全身照片、身高、体重和穿搭偏好。这些数据应按敏感个人信息的标准处理。

## 当前数据流

- Flutter 在本地读取用户主动选择的照片。
- 客户端压缩并编码图片，通过 API 发送给 Node。
- Node 不将图片写入磁盘或数据库，直接转发给配置的 AI 供应商。
- Node 日志不记录请求正文、Base64 或模型输入。

## 生产要求

- 客户端到 API、API 到 AI 供应商全链路 TLS。
- 上传前明确说明处理目的，并取得用户主动同意。
- 提供隐私政策、供应商说明、数据保留时间和删除渠道。
- 默认不保存原始照片；如确需保存，使用独立对象存储、短期签名 URL、服务端加密和自动过期。
- API Key 只保存在服务端密钥管理系统，不进入 Flutter、Git 或日志。
- 对请求频率、并发、图片大小和供应商费用设置硬限制及告警。
- 用户可撤回同意并删除账户及历史数据。
- 穿搭分析不得作为医疗、健康或身体评价结论。

## 日志规则

允许记录：

- 请求 ID
- HTTP 方法和路由
- 状态码、耗时
- 上游错误类型和非敏感错误码

禁止记录：

- Base64、图片 URL 或图片内容
- 完整请求正文
- API Key
- 用户自由文本原文
- 可直接识别个人身份的信息
