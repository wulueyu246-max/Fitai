# 文档导航

本目录用于固化树皮 Shupi（FitAI）的开发上下文，避免人员、会话或工具切换后丢失关键决策。

| 文档 | 用途 |
| --- | --- |
| [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md) | 已完成工作、关键排障过程与最终方案。 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Flutter、Node、DashScope 与 UI 的职责边界。 |
| [API.md](API.md) | `/outfit` 请求、响应与错误契约。 |
| [PRODUCT_RECOMMENDATIONS.md](PRODUCT_RECOMMENDATIONS.md) | 商品推荐模型、数据库与接口扩展设计。 |
| [ROADMAP.md](ROADMAP.md) | 后续版本的建议路线，不代表已实现。 |
| [CHANGELOG.md](CHANGELOG.md) | 对外可读的版本变更记录。 |
| [PRODUCTION_DEPLOYMENT.md](PRODUCTION_DEPLOYMENT.md) | 生产部署与人工配置说明。 |
| [PRIVACY_SECURITY.md](PRIVACY_SECURITY.md) | 隐私与安全要求。 |

根目录 [README.md](../README.md) 提供项目介绍和本地启动命令。
