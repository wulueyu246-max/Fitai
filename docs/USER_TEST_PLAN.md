# FitAI V1.2 真实用户测试计划

## 1. 测试目标

用 50–100 名真实目标用户验证四件事：用户能否顺利完成首次 AI 穿搭、是否认可推荐、商品解释是否提高购买意愿、虚拟试穿是否促进收藏和购买跳转。

## 2. 样本与周期

- 样本：50–100 人，覆盖不同性别、身高、体型、职业和预算。
- 周期：首轮 7 天，复测 7 天。
- 设备：移动端浏览器优先，同时覆盖鼠标、触控板和触屏。
- 分组：至少 20 人完整体验商品详情和试穿；至少 10 人完成二次回访。

## 3. 首次测试任务

1. 打开 FitAI，完成身份、身高、体重、年龄段、职业、场景和预算设置。
2. 上传一张正面全身照；愿意时补充侧面和背面照片。
3. 生成第一套 AI 穿搭方案，查看身体分析、风格定位、场景与匹配度。
4. 使用“换上衣 / 换裤子 / 换鞋”，确认方案会即时更新。
5. 查看至少一件商品详情，阅读身材、风格、场景三类推荐原因。
6. 点击“立即试穿”，等待 Mock 结果，执行保存、再次生成或分享。
7. 收藏一件商品，并点击一次“立即购买”完成模拟购买跳转。
8. 提交“喜欢 / 一般 / 不喜欢”、满意度、购买意愿与不购买原因。

## 4. 记录指标

| 阶段 | 事件/指标 | 目标 |
| --- | --- | ---: |
| 注册/首启 | `new_user_onboarding_completed` | 完成率 ≥ 70% |
| 照片 | `photo_upload_completed` | 首启到上传 ≥ 65% |
| AI 生成 | `outfit_generated` | 上传到生成 ≥ 85% |
| 商品 | `product_detail_view` | 生成到详情 ≥ 35% |
| 意向 | `purchase_intent` | 详情到购买按钮 ≥ 12% |
| 转化代理 | `product_purchase_redirect` | 点击购买到外链 ≥ 90% |
| 反馈 | `recommendation_feedback_submitted` | 反馈提交 ≥ 30% |

同时记录：任务完成率、首次生成耗时、商品点击率、收藏率、试穿率、购买意向率、平均满意度、不购买原因分布和测试者原话。

## 5. 访谈问题

- 哪一步最难理解或最不愿继续？
- 推荐原因是否让你相信这件商品适合自己？
- 你更关注身材、风格还是场景解释？
- Mock 试穿能否帮助做决定？若不能，缺少什么？
- 什么价格或服务会让你愿意付费？

## 6. 数据与隐私

- 测试前展示用户协议、隐私授权和照片用途。
- 运营事件不上传身高、体重或照片内容；只记录匿名安装 ID 和必要行为字段。
- 用户可在隐私中心删除本地照片。
- 真实照片不得进入演示数据、截图或公开材料。

## 7. 通过标准

V1.2 进入下一阶段需同时满足：首次流程完成率 ≥ 70%，上传到生成 ≥ 85%，商品详情率 ≥ 35%，购买意向率 ≥ 12%，严重阻断问题为 0。未达标时先根据漏斗最大流失点修正，不新增无关功能。
